## 验证口径

- Windows / Python 3.13：`pytest -q` 63 项通过；前端 JavaScript 语法检查、Compose 配置检查通过。
- 浏览器：预算补充与重新规划、P1001 的 20 万申请/5 万缺口、草稿确认提交、模拟翻译、知识问答、390 像素移动布局及 DeepSeek 缺密钥提示已验证。
- 开发集冒烟：可回答题文档 Hit@3 为 19/19，无答案题 1/1，预期字符串包含 20/20。这些是 Mock 加字符向量的小型合成集结果。
- 六组检索/分块消融及误召回记录见 [本轮实现与验证](./06-advanced-rag-and-ingestion.md)。新增浏览器检查覆盖排名追踪、独立 Worker 发布、双 Agent 交接及移动布局。

自动测试覆盖主要闭环。DeepSeek/Ollama 流式接口及音频服务使用模拟 HTTP 响应验证；MCP stdio 使用真实子进程，HTTP 通道也已实际连通。Mock 预算 Agent 确实通过 Pydantic AI 调用工具，但决策由确定性 FunctionModel 提供。

尚未配置 DeepSeek API Key 或真实音频服务，没有真实模型任务成功率、翻译质量或语音准确率结果。字符哈希开发集仅用于冒烟，不代表语义检索准确率。运行命令见[项目 README](../README.md)。
